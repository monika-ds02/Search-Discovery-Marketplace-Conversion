# Search Discovery Marketplace Conversion

## Project Overview
This project focuses on analyzing search discovery, query quality, product ranking, customer interactions, and marketplace conversion performance.

## Project Objectives
- Analyze search query performance.
- Evaluate search result quality.
- Understand product discovery and ranking.
- Analyze search clicks and conversion metrics.
- Identify opportunities to improve marketplace performance.

## Technologies Used
- SQL
- Microsoft Excel
- Power BI
